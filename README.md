# 塹壕戦 1917 — VERDUN FRONT

ブラウザで動くシングルHTMLのミニゲームです。`index.html` から開始し、ゲーム本編は `game.html` で動作します。

## 動かし方（最短）

### 1) ブラウザで開く
- `index.html` をブラウザで開く
- 画面の「戦場に入る / プレイする」ボタンを押す → `game.html` に遷移して開始

※ブラウザの設定によっては、ローカルファイル（`file://`）で開くと一部機能（スコア送信など）が制限される場合があります。その場合は、次の「ローカルサーバー」を推奨します。

### 2) ローカルサーバーで開く（推奨）
Python がある場合、リポジトリ直下で以下を実行します。

```bash
python3 -m http.server 8000
```

その後ブラウザで以下を開きます。

- http://localhost:8000/

## 操作方法

タイトル画面にも表示されます。

- クリック：射撃
- R：装填（リロード）
- Space：銃剣突撃
- W / S：前後移動（演出・ログ）
- A / D（または ← / →）：左右移動（左翼・中央・右翼）
- C：カバー（被ダメージ軽減）
- M：防毒マスク（毒ガス攻撃時）

画面下部のボタンからも実行できます：手榴弾、回復薬、スコップ近接、防毒マスク、戦車呼出（条件あり）。

## ゲーム概要

- Wave制（全8Wave）
- 敵種：歩兵 / 突撃兵 / 狙撃兵 / 機関銃兵
- 撃破・行動でスコアとXPを獲得し、昇格するとスキルが解放されます
- 毒ガス・砲撃・戦車イベントなどがWaveに応じて発生します

## スコア送信・ランキング（任意）

エンド画面には「スコア送信」と「ランキング表示」がありますが、これは **外部のAPIサーバー** が必要です。

- APIの接続先は `塹壕戦争.html` 内の `API_BASE` で指定されています（初期値：`http://localhost:8000`）
- サーバー未起動の場合は、送信やランキング欄に「接続できません」が表示されます（ゲーム自体はプレイ可能）

必要に応じて、`API_BASE` を自分のサーバーURLに変更してください。

## ファイル構成

- `index.html`：タイトル/導入ページ（ボタンでゲームへ遷移）
- `game.html`：ゲーム本体（UI・ロジック一体）
- `塹壕戦争.html`：旧ファイル名のゲーム本体（互換用に残しています）
- `style.css` / `main.js`：現状 `index.html` からは読み込まれていません（必要なら後で整理可能）
